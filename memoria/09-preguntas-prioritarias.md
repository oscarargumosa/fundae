# Las 20 preguntas de diagnóstico prioritario

Úsalas como guion cuando una pregunta del usuario sea ambigua o de alcance amplio: resolver
primero estas, en este orden, suele destrabar el resto.

1. **¿Soy empresa bonificada, gestor, entidad organizadora o entidad de formación?** → [[01-roles-y-figuras]]
2. **¿Debo inscribirme/acreditarme para hacer este trabajo?** → [[01-roles-y-figuras]]
3. **¿La empresa tiene derecho a crédito y cuánto crédito posee?** → [[02-credito-costes-cofinanciacion]]
4. **¿Qué importe máximo puedo bonificar realmente?** → [[02-credito-costes-cofinanciacion]] (el menor de crédito/coste/módulo)
5. **¿Con cuánta antelación debo comunicar el inicio?** → [[03-proceso-plazos-rlt]]
6. **¿Debo informar a la RLT?** → [[03-proceso-plazos-rlt]]
7. **¿Qué trabajadores son elegibles?** → [[06-participantes-elegibilidad]]
8. **¿Qué requisitos debe cumplir el curso para ser bonificable?** → [[08-ayudas-legal-herramientas]]
9. **¿Qué porcentaje debe completar el alumno?** → [[03-proceso-plazos-rlt]] (75 %)
10. **¿Qué documentos debo guardar y durante cuánto tiempo?** → [[04-documentacion-custodia]] (4 años)
11. **¿Cuándo y cómo aplico la bonificación en Seguridad Social?** → [[03-proceso-plazos-rlt]]
12. **¿Cuál es el plazo final del ejercicio?** → [[03-proceso-plazos-rlt]] (¡ojo, no es simplemente "31 de diciembre" desde 2026!)
13. **¿Cuánta cofinanciación privada debe aportar la empresa?** → [[02-credito-costes-cofinanciacion]]
14. **¿Qué costes directos, indirectos y de organización son admitidos?** → [[02-credito-costes-cofinanciacion]]
15. **¿Necesito contrato de encomienda y qué debe decir?** → [[01-roles-y-figuras]]
16. **¿El proveedor de formación debe estar inscrito?** → [[01-roles-y-figuras]] (depende de si hay organizadora externa o autoorganización)
17. **¿Puedo impartir en Zoom/Teams como formación presencial?** → [[07-modalidad-aula-virtual]]
18. **¿Qué ocurre si FUNDAE/SEPE considera incorrecta la bonificación?** → [[05-auditoria-sanciones-fraude]]
19. **¿Qué conductas pueden constituir fraude y qué responsabilidad tiene la organizadora?** → [[05-auditoria-sanciones-fraude]]
20. **¿Puedo acumular crédito o conseguir crédito adicional por ERTE?** → [[02-credito-costes-cofinanciacion]]
