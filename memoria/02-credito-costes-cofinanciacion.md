# Crédito, límites económicos y cofinanciación

Ver [[00-resumen-ejecutivo]]. **Regla central: el importe bonificable real es el MENOR entre
crédito disponible, coste admitido y límite económico/módulo aplicable.** Tener crédito no
garantiza que todo el precio facturado sea bonificable.

## Regla de oro para responder cualquier pregunta de importe

1. ¿Cuánto crédito queda?
2. ¿Cuál es el coste real admitido (directo + indirecto ≤10% + organización ≤10/15/20%)?
3. ¿Qué módulo/límite económico aplica a esa modalidad y ejercicio?
4. El importe bonificable es el **menor** de los tres.
5. Si la empresa tiene ≥6 trabajadores, falta comprobar la cofinanciación privada mínima.
